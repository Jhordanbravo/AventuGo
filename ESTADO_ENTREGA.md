## Sin bloqueos conocidos

El proyecto se puede abrir directamente desde `dist/index.html`, aunque se recomienda usar Live Server para conservar el comportamiento normal de `localStorage`.

Antes de publicarlo en el portafolio, conviene hacer una última revisión en el navegador y dispositivo donde se tomarán las capturas finales.
